Import depuis PlaudSans exporter à la main (facultatif)
  1. Sur un ordinateur, connecte-toi à web.plaud.ai.
  2. Ouvre la console (touche F12, onglet « Console »). Touche , colle-la dans la console, puis Entrée.
  3. Le jeton est copié (« Jeton copié »). Colle-le dans le champ ci-dessus, puis touche « Tester la connexion ».
La commande cherche le jeton toute seule, quel que soit le nom que Plaud lui donne. Si Chrome refuse de coller, tape d'abord allow pasting puis Entrée, et recommence.
Sans ordinateur (Chrome Android) : touche , crée un favori dans Chrome et remplace son adresse par ce code. Ouvre ensuite web.plaud.ai, connecte-toi, tape le nom du favori dans la barre d'adresse et touche-le : le jeton s'affiche, prêt à copier.
Le jeton reste dans ce téléphone. Il expire au bout de quelques semaines ou mois : il suffira de le recopier. L'API de Plaud n'est pas officielle et peut changer sans prévenir.
